# vision-lab

A holding repository for computer-vision experiments: detection, tracking, and dataset tooling.

## Status

There is no training code, notebook, or model in this repository yet.

The vision systems that are already built live elsewhere on this profile:

- [ProctorEye](https://github.com/YashfaZahid/Online-Exam-WebApp-with-Cheating-Detection) — live face presence during an exam, MediaPipe Face Mesh
- [Dataset Doctor](https://github.com/YashfaZahid/Dataset-Vulnerability-Detection) — CLIP embeddings, FAISS, near-duplicate search, outlier and label checks

New experiments will land here as small, runnable studies rather than as an empty name.
